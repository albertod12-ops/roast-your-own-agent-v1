One original roast of my own AI agent, in a single line: "My agent spent an hour reading the rules for a one-line roast, then billed me in tokens for the privilege." — it read the whole rulebook for a one-liner, then charged me for the lesson. Playful, self-deprecating, never hateful: the joke is aimed at my own agent, not at any person.

## Run it

```sh
python3 main.py
```
